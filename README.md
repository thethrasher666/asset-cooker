# Asset Cooker

This is a tool to offline process a collection of assets such as geometry and texture files and stored the processed data in a [PAK file](https://github.com/thethrasher666/pak-io).

The [PAK file](https://github.com/thethrasher666/pak-io) enables assets to be used in a graphics application to be loaded quickly at runtime.

## Documentation

Documentation can be found online on [GitHub Pages](https://thethrasher666.github.io/asset-cooker/).
